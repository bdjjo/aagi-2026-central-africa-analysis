# Data dictionary

All processed tables live in `data/processed/` and are regenerated by
`code/aagi_analysis.py`. Fields below are grouped by the file that carries them.

## `report_comparative_summary.csv` / `report_summary_with_tiers.csv`

| Field | Meaning | Source | Type / unit |
|---|---|---|---|
| `Country` | Country label in the report summary | Report p. 2 | Categorical |
| `P1 Strategy` … `P8 Implementation` | Pillar scores | Report p. 2 | Numeric, 0–4 |
| `Composite` | Reported approximate composite | Report p. 2 | Numeric, 0–4 |
| `Tier` | Descriptive band from composite (Pre-Governance <0.5; Nascent 0.5–1.0; Developing 1.0–2.0; Established+ >2.0) | Derived | Categorical |

## `report_pillar_scores_long.csv`

Long form of the summary: one row per country × pillar.

| Field | Meaning | Source | Type / unit |
|---|---|---|---|
| `Country` | Country label | Report p. 2 | Categorical |
| `Composite` | Reported composite for that country | Report p. 2 | Numeric, 0–4 |
| `Pillar` | Pillar name (P1–P8) | Report p. 2 | Categorical |
| `Score` | Pillar score | Report p. 2 | Numeric, 0–4 |

## `pillar_descriptive_stats.csv`

| Field | Meaning | Type |
|---|---|---|
| `Pillar` | Pillar name | Categorical |
| `Mean`, `Median`, `Min`, `Max`, `Range` | Descriptive statistics across the six countries | Numeric, 0–4 |
| `SD_population` | Population standard deviation (ddof=0), n = 6 | Numeric |

## `country_composite_ranking.csv`

| Field | Meaning | Type |
|---|---|---|
| `Country` | Country label | Categorical |
| `Composite` | Reported composite, sorted descending | Numeric, 0–4 |

## `pillar_spearman_correlation.csv`

8×8 Spearman rank-correlation matrix among pillars. **Descriptive only** — n = 6,
not inferential; pillars may share underlying evidence.

## Workbook audit tables

### `workbook_pillar_completeness.csv`

| Field | Meaning | Source | Type |
|---|---|---|---|
| `sheet` | Pillar sheet name | Workbook P1–P8 | Text |
| `indicator_rows` | Designed indicator rows (10 per pillar) | Workbook | Integer |
| `filled_indicator_rows` | Rows with any score/evidence/source/note | Workbook rows 5–14 | Integer |
| `country`, `fellow`, `date` | Sheet metadata (`[Enter]` where unfilled) | Workbook row 2 | Text |

### `workbook_pillar_records.csv`

| Field | Meaning | Source | Type |
|---|---|---|---|
| `sheet`, `row` | Location of the record | Workbook | Text/Integer |
| `id` | Indicator identifier (e.g. S1.1, G2.1) | Workbook col A | Text |
| `indicator` | Indicator name | Workbook col B | Text |
| `score` | Indicator score | Workbook col E | Numeric, 0–4 |
| `evidence` | Supporting evidence text | Workbook col F | Text |
| `source` | URL / document reference | Workbook col G | Text |
| `notes` | Context and gap notes | Workbook col H | Text |

### `workbook_supporting_sheet_audit.csv`

| Field | Meaning | Source | Type |
|---|---|---|---|
| `sheet` | Supporting sheet name | Workbook | Text |
| `nonempty_rows` | Rows with any content (incl. template labels) | Workbook | Integer |
| `non_placeholder_values` | User-entered, non-`[Enter]`, non-label values | Workbook | Integer |

## Missingness convention

Blank workbook cells mean **no entry was supplied**; they are **not** converted
to zero. A report score of 0 is retained because it is part of the published
comparative summary, but under the report's methodology it denotes *no findable
primary evidence*, not definitive absence.
